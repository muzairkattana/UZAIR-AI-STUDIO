## 🌟 Executive Overview
**Uzair AI Studio** is a modern full-stack web ecosystem and enterprise software studio specializing in advanced AI agent engineering, custom SaaS architecture, computer vision solutions, and full-lifecycle technical training.

The platform combines a client-facing digital showroom with a production-grade Executive Command Hub, interactive architecture sprint planner, cryptographically verifiable candidate credentials, and multi-tier QR code scanning.

---

## 🚀 Key Modules & System Capabilities

### 1. 🏛️ Studio Showcase & Interactive Architecture Engine
* **Interactive Project Architecture Planner**: Progressive disclosure planner for technical founders and enterprise CTOs to architect custom software stacks, select AI/LLM models, database engines, cloud infrastructure, and estimate delivery sprints.
* **Direct Architecture Brief Ingestion**: Client briefs automatically feed into dual telemetry stores and register inquiries directly into the Executive Consultations cockpit.

### 2. 🎓 Verifiable Internship Credential Ecosystem
* **1:1 Official Certificate of Completion**: High-resolution landscape credential featuring multifaceted gold/sapphire geometric crystal borders, golden medallion ribbon seal, dual authentic signatures (Founder Muhammad Uzair & Supervisor Engr. Saad), and embedded verification QR.
* **Official Internship Offer Letters**: Print-ready, high-fidelity A4 appointment documents with official studio digital seals.
* **Letters of Recommendation (LOR)**: Endorsed academic and professional recommendation credentials.
* **Strict Tenure Access Control**: Certificates and Recommendations are cryptographically protected and automatically unlock only upon successful completion of the full 2-month training duration. Active interns retain access to their Offer Letters while tracking live tenure countdowns.

### 3. 🔍 Industrial 3-Tier QR Verification Engine
* **Tier 1 (Native Hardware API)**: Accelerates verification via browser-native `BarcodeDetector`.
* **Tier 2 (ZXing Computer Vision Engine)**: Utilizes `ZXing.BrowserQRCodeReader` with `TRY_HARDER` enabled across raw image elements and Base64 URLs to decode tilted, skewed, or noisy captures.
* **Tier 3 (Multi-Pass Adaptive `jsQR`)**: Employs alpha-channel flattening, 5 adaptive luminance thresholds (`[85, 110, 135, 160, 185]`), contrast-stretching normalization, and quadrant cropping for documents and digital badges.

### 4. 👑 Executive Admin Command Portal
* **Live Telemetry & Real-Time Analytics**: Visual KPI widgets tracking candidate volume, conversion funnels, top tech tracks, geographic distribution, and real-time activity feeds.
* **Candidate & Consultation Management**: Dual-mode data tables and responsive card grids with inline status toggling, CSV exports, WhatsApp automation, and record modification.
* **Responsive Architecture**: Fully optimized across desktop, tablet split-screens, and mobile phone layouts.

## 📦 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v16.0.0 or higher recommended)
* `npm` package manager

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/muzairkattana/UZAIR-AI-STUDIO.git
   cd UZAIR-AI-STUDIO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   node server.js
   ```

4. Open your browser and navigate to:
   * **Studio Main Website**: `http://localhost:3000`
   * **Public Verification Portal**: `http://localhost:3000/verify`
   * **Executive Command Hub**: `http://localhost:3000/admin`
